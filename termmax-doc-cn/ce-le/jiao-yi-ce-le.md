# 💲 交易策略

以下表格列出了针对借入代币利率变动时，FT和XT的推荐交易策略：

| <p><br></p> | FT策略   | XT策略   |
| ----------- | ------ | ------ |
| 利率上升        | 卖出（做空） | 买进（做多） |
| 利率下降        | 买进（做多） | 卖出（做空） |



### 策略概览

#### 当利率上升时：

* **FT（固定收益代币）**\
  **卖出（做空）**：\
  当市场利率上升时，FT所提供的固定收益相较于新利率而言吸引力下降。通过卖出FT，投资者可以在FT因市场利率升高而价值可能降低之前锁定收益。
* **XT（利息代币）**\
  **买入（做多）**：\
  上升的利率可能提高XT代表的杠杆头寸的潜在收益。买入XT能帮助投资者利用更高的市场利率，提升杠杆收益。

#### 当利率下降时：

* **FT（固定收益代币）**\
  **买入（做多）**：市场利率下降使FT提供的固定利率更具吸引力。买入FT让投资者在市场利率持续走低的情况下锁定更高的固定收益。
* **XT（利息代币）**\
  **卖出（做空）**：下降的利率可能降低XT相关的杠杆头寸收益。卖出XT可帮助投资者避免杠杆收益减少的风险。

### 重要注意事项

* **风险承受能力**：
  * **FT代币**：提供较为稳定和可预测的收益，风险较低，适合追求稳定性的保守投资者。
  * **XT代币**：由于杠杆性质和收益波动，风险较高，更适合风险偏好较高、寻求高倍收益的投资者。
* **交易成本与费用**：\
  注意交易XT和FT代币（无论买入、卖出或做多、做空）涉及的Gas费用及平台手续费。较高的交易成本可能会侵蚀潜在利润，特别是对频繁交易者而言。
