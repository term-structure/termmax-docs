# 🐳 范围订单设定方

在TermMax平台上，范围订单设定方通过放置附带定价曲线的**范围订单**，根据自身策略和当前市场状况，灵活定义其借贷意图。这些定价设定者利用平台的固定利率代币化机制，实现财务目标的最优化。TermMax提供三种类型的范围订单：

1. **借款范围订单**\
   借款方希望通过附带**借款定价曲线**的范围订单，以固定利率获取债务代币（如USDC）。该定价曲线通常设定为：**前期成交部分的借款利率较高**，而随着订单逐步成交，**后续成交部分的利率逐渐降低**。这种安排帮助借款方有效控制整体借贷成本，同时在市场波动时保持灵活性。
2. **放贷范围订单**\
   贷方则通过附带放贷定价曲线的范围订单，获取固定收益。他们通常设定初始部分成交的利率较低，随着订单逐渐被满足，后续部分的利率逐步提高。这种策略确保贷方在资本逐渐配置时获得更具竞争力的收益，进而实现利润最大化。
3. **双向范围订单**\
   双向范围订单设定方同时结合了借贷双方的策略，仅使用单一的范围订单，同时包含两条不同的定价曲线：
   * 一条**较低利率**的**借款曲线**，当借款吃单方填补订单时，降低其自身的借贷成本。
   * 一条**较高利率**的**放贷曲线**，当放贷吃单方填补订单时，实现更高的收益率。

通过捕捉借贷两侧的利差，双向范围订单设定方可根据市场活动动态调整自身角色，从而优化资本配置与风险管理。
