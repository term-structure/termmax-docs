# 杠杆交易者

在TermMax平台上，**杠杆市场接受方**是一种**特殊类型的借款人**，其特点是将所借出的债务代币重新投入购买抵押资产，从而放大对抵押资产的敞口。与传统借款人将借入的债务代币用于外部用途不同，杠杆市场接受方利用TermMax高效、固定利率机制以及**闪电贷**（Flash Loan）来优化杠杆交易流程。借入的债务代币与初始投入结合，用于购买抵押资产，并锁定于**杠杆代币（GT）**&#x4E2D;。这一机制使得杠杆市场接受方可以在单一交易中，高效、安全地实现杠杆敞口。

## 运作流程&#x20;

杠杆市场接受方执行杠杆交易步骤如下：

1. **提供债务代币：** \
   杠杆市场接受方首先提供债务代币（如USDC），作为创建杠杆头寸的初始资金输入。
2. **闪电贷借款：** \
   使用初始提供的债务代币，杠杆市场接受方通过**闪电贷**借入更多的债务代币。初始提供的代币和借入的代币共同构成购买抵押资产的资金总量。
3. **购买和锁定抵押资产：** \
   将上述资金总量用于购买期望的抵押资产（例如ETH）。购得的抵押资产锁定在**GT**中，记录该杠杆头寸的总抵押资产和债务金额。
4. **发行及拆分固定利率代币（FT）：**&#x20;
   1. 锁定在GT中的抵押资产用于发行**固定利率代币（FT）**。&#x20;
   2. **发行的FTs分为：**&#x20;
      1. **本金部分：**&#x4EE3;表借入债务代币的等值金额。&#x20;
      2. **利息部分：**&#x4EE3;表支付给贷款市场提供方的固定收益。
5. **XT兑换与闪电贷偿还：**&#x20;
   1. FTs的利息部分通过贷款范围订单出售，兑换为X代币（XT）。
   2. &#x20;兑换所得的XT与FT本金部分共同用于赎回债务代币（如USDC）。&#x20;
   3. 赎回的债务代币用于**偿还闪电贷**，完成整个交易。
6. **最终杠杆头寸：** \
   交易完成后，杠杆市场接受方获得一个**GT**，反映杠杆头寸情况。GT记录了锁定的抵押资产及总债务义务。

## 杠杆机制

1. **债务代币投入：** \
   杠杆市场接受方首先投入一定数量的债务代币，构建杠杆头寸基础。
2. **闪电贷借款：**&#x20;
   1. 闪电贷机制使杠杆市场接受方无需预先抵押便能借入更多债务代币。
   2. 借入的债务代币加上初始投入，共同用于购买更多抵押资产。
3. **购买并锁定抵押资产：**&#x20;
   1. 债务代币总量用于购买额外的抵押资产（如ETH）。
   2. 购入的抵押资产被锁定在**GT**中，追踪杠杆头寸的总抵押资产和债务。
4. **发行FT：**&#x20;
   1. 锁定的抵押资产允许发行FTs。
   2. **每发行一个FT**，对应金额的债务记录在GT中。
5. **FT拆分与XT兑换：**&#x20;
   1. 发行的FTs分为**本金**和**利息**两部分：&#x20;
      1. **本金部分：**&#x4EE3;表借入债务代币金额。&#x20;
      2. **利息部分：**&#x4EE3;表贷款市场提供方的固定收益。
   2. FTs的利息部分出售给贷款范围订单，兑换为XTs，确保固定收益在系统中得到体现。
6. **闪电贷偿还：**&#x20;
   1. 兑换得到的XTs与本金部分的FTs合并，赎回债务代币（如USDC）。
   2. 赎回的债务代币用于偿还闪电贷，完成杠杆交易。
7. **最终GT状态：**&#x20;
   1. GT记录了杠杆市场接受方的总杠杆债务与锁定的抵押资产，体现其杠杆头寸。&#x20;
   2. 此时，杠杆市场接受方已完全实现抵押资产的杠杆敞口。

## 案例示范：Alice作为杠杆交易者

1. **提供债务代币：** \
   Alice投入**1,000 USDC**创建杠杆头寸。
2. **闪电贷借款：**&#x20;
   * Alice通过闪电贷再借入**2,000 USDC**，总资金达到**3,000 USDC**。
3. **购买并锁定抵押资产：**&#x20;
   * Alice用**3,000 USDC**购买了**3枚ETH**（假设ETH价格为每枚1,000美元）。
   * **3枚ETH**被锁定在GT中。
4. **发行与拆分FTs：**&#x20;
   * 锁定的**3枚ETH**用于发行**2,100个FT**。&#x20;
   * 其中FT分为：&#x20;
     * **2,000 FT**：代表所借债务代币金额。&#x20;
     * **100 FT**：代表贷款市场提供方的固定收益。
5. **XT兑换与闪电贷偿还：**&#x20;
   * Alice将**100个FT（利息部分）**&#x51FA;售给贷款范围订单，兑换为**2,000个XT**。&#x20;
   * 将**2,000个XT**与**2,000个FT（本金部分）**&#x5408;并，赎回**2,000 USDC**。&#x20;
   * 赎回的**2,000 USDC**用于偿还闪电贷。
6. **杠杆交易后状态：**&#x20;
   * 交易完成后，Alice的GT情况为：&#x20;
     * **3枚ETH**锁定为抵押资产。&#x20;
     * **2,100 USDC**记作债务。&#x20;
   * Alice成功创建了一个对ETH放大敞口的杠杆头寸。

## 优势

1. **高效创建杠杆：**\
   &#x20;杠杆市场接受方通过TermMax的闪电贷机制实现单笔交易的高效杠杆，无需重复步骤。
2. **放大市场敞口：** \
   作为特殊的借款人，杠杆市场接受方将借入的债务代币重新用于购买抵押资产，从而极大化对目标资产的敞口。
3. **固定利率稳定性**： \
   固定利率借贷保证了成本的可预测性，降低了市场利率波动带来的风险。
4. **安全的超额抵押：** \
   锁定在GT中的抵押资产保障了杠杆头寸的安全性，降低了杠杆市场接受方与平台双方的风险。

## 总结

TermMax的杠杆市场接受方是一种特殊的借款人，他们将借入的债务代币再投资于抵押资产，放大其对资产的敞口。通过结合债务代币投入、闪电贷机制及GT抵押资产锁定，杠杆市场接受方能够高效、安全地创建杠杆头寸，并获得固定利率借贷及超额抵押的优势。这一角色适合希望以安全、去中心化方式提高对抵押资产敞口的用户。
