# 🐬 市场吃单方

在 TermMax 平台上，市场接受方与市场做市商设定的**区间订单**进行交互，以满足自身的借贷需求。与市场做市商设定价格曲线不同，市场接受方只是根据自身的财务目标来匹配并完成这些已存在的订单。市场接受方可分为三种类型：

1. **借款市场吃单方**\
   借款市场吃单方旨在通过匹配借出市场做市商设定的区间订单，以获得债务代币（如 USDC）用于自身财务需求。他们将抵押资产锁定在**杠杆代币（GT）**&#x4E2D;，发行**固定利率代币（FT）**&#x4EE5;代表自身债务，并按借出曲线中指定的利率将这些固定利率代币兑换为所需的债务代币。借款市场接受方可因此享受到可预测且固定的借贷成本。
2. **放贷市场吃单方**\
   放贷市场吃单方向平台提供债务代币，通过匹配**借款市场做市商设定的区间订单**以赚取固定收益。他们借出的债务代币用于铸造**FT**和**XT**，所获得的**XT**确保他们获得借款曲线中约定的固定收益率。借出市场接受方无需自己定义价格曲线，即可获得稳定、可预测的收益。
3. **杠杆交易者**\
   杠杆交易者是借款市场接受方中的特殊类型，他们利用借入的债务代币以扩大其在特定资产上的市场敞口。与单纯将借入资金用于外部用途不同，他们将借入的债务代币重新投资到基础抵押资产中，并将抵押资产锁定于**GT**内，从而创建杠杆头寸。这一过程通过**闪电贷（Flash Loan）**&#x5728;单笔交易中完成，使其无需循环借贷即可最大化市场敞口。
