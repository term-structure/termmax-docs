# 💵 交易费用说明

### 贷款交易费用

#### 计算公式：

借出交易费率 = APR × 借出费率 ×（距到期天数 ÷ 365）

借出交易费用 = 借出交易费率 × 借出金额

当前协议设定的借出费率为 2%。

{% hint style="info" %}
**示例：**&#x82E5;借出利率（APR）为 10%，借出金额为 1,000 USDC，距到期日为 365 天：

* 借出交易费率 = 10% × 2% × (365/365) = 0.2%
* 交易费用 = 0.2% × 1,000 = 2 FT
{% endhint %}



### 借款交易费用

#### 计算公式：

借入交易费率 =【GT 铸造参考利率 × GT 铸造费率 + 匹配借款利率 × 借入费率】×（距到期天数 ÷ 365）

借入交易费用 = 借入交易费率 × 借入金额

当前协议参数：

1. 借入费率：3%
2. GT 铸造参考利率：
   * 稳定币：10%（随市场条件而变化）
   * 非稳定币：4%
3. GT 铸造费率：10%

{% hint style="info" %}
**示例：**&#x5047;设匹配借款利率为 6%，借入资产为 1,000 USDC，距到期日为 90 天：

*   借入交易费率 =【10% × 10% + 6% × 3%】× (90/365)

    \= (1% + 0.18%) × (90/365)

    \= 1.18% × (90/365)

    \= 0.290955%
* 交易费用 = 0.290955% × 1,000 ≈ 2.90955 FT
{% endhint %}



### 杠杆交易费用

#### 计算公式：

杠杆交易费率与借入交易费率一致。

总借入金额 = 投入金额 ×（杠杆倍数 - 1）

杠杆交易费用 = 总借入金额 × 借入交易费率

{% hint style="info" %}
**示例：**&#x5047;设借入交易费率为 0.290955%，投入金额为 1,000 USDC，杠杆倍数为 4.8：

*   杠杆交易费用 = 1,000 × (4.8 - 1) × 0.290955%

    \= 1,000 × 3.8 × 0.290955%

    ≈ 11.05629 FT
{% endhint %}
