# 【第二期】TermMax Mindshare 专属创作者激励计划

首期 TermMax Mindshare 专属创作者激励计划已顺利结束，社区参与热情与内容质量均超出预期，感谢各位创作者的积极参与与支持。

基于社区反馈与 TermMax Mindshare 的持续增长，我们将推出第二期创作者激励计划，并对准入门槛、评分机制与激励结构进行升级，进一步聚焦产出高质量内容的创作者。

#### 注意事项

* 本激励计划榜单与 TermMax 官方 Mindshare Leaderboard 为独立榜单。加入本计划后，您的内容将同时计入 TermMax 官方 Mindshare Leaderboard 与本计划独立榜单，享受双重激励。

**`官方榜单：面向所有用户的长期活动，展示用户获得 MP（Mindsahre Points）的排名。`**

**`本计划：面向符合条件创作者的限时激励活动榜单。`**<br>

* 仅成功报名并在活动期内完成相应参与要求的创作者，才具备该计划排行榜评选及领奖资格（含保底奖励）。
* 报名不代表自动入选，官方将在报名截止后 3 个工作日内联系通过审核的创作者。

### 一、报名时间

自公告发布起开放报名，名额有限，招满即止。官方将根据报名情况决定最终截止时间。\
报名表：[https://forms.gle/8utfxAhXxU1ebbmM9](https://forms.gle/8utfxAhXxU1ebbmM9)

### 二、参与资格

#### 1. 报名条件

* X粉丝数 ≥ 5,000
* 过去 30 天内，至少有 1 条推文浏览量 ≥ 5,000

#### 2. 内容与参与要求（最低门槛）

成功加入本计划的创作者，需在指定的一周活动周期内完成以下要求。未在该周期内完成最低参与要求的，将不进入排行榜评选范围，也不具备领奖资格。

**官方互动**

* 至少 3 次 与 @TermMaxFi 官方账号互动\
  （包括评论 / 转发 / 引用推文，形式不限，官方可能指定互动推文）

**原创内容**

* 活动期间发布 ≥ 3 条 TermMax 相关原创内容
* 内容形式不限（Thread / 图文 / 视频等形式均可）

**内容需包含**

* 至少一条内容与 TermMax Mindshare 及 MP（Mindshare Points）相关
* 内容可结合项目相关信息，如：

> 产品机制 / 项目亮点\
> 使用体验/教程\
> 积分体系 / 空投参与方式\
> 官方动态或个人观点

* 内容中需 @TermMaxFi

**内容质量要求**

* 内容需体现真实投入与原创性
* 抄袭、水帖、低质量内容将被取消排名资格

### 三、激励结构

除官方 Mindshare Leaderboard 自带的积分奖励外，本计划独立榜单额外提供保底奖励 + 进阶排名奖励。所有奖励（USDC/MP）将在计划结束后 10 个工作日内，根据最终确认排名统一结算发放。

#### 1. 基础奖励（保底）

所有完成最低参与要求的创作者：100 USDC

#### 2. 进阶激励（排行榜）

| **排名**   | **奖励**                             |
| -------- | ---------------------------------- |
| 第 1 名    | 500 USDC                           |
| 第 2 名    | 350 USDC                           |
| 第 3 名    | 250 USDC                           |
| 第 4–10 名 | 一次性 MP 奖励（3,000 MP → 500 MP，按排名递减） |

#### 3.额外激励

活动期间的 X 名字带上官方 Name Tag【🐬TermMax】，获得一次性 500 MP 激励。

### 四、排名与评分机制

本期创作者激励计划的排名评估，将以统一时间点的数据统计为基础，结合加权评分与人工审核进行。为确保评选公平公正，具体加权公式将不对外公开。

#### 数据收集与统计范围

* 仅统计活动期间内发布的前三篇内容，超出的内容不统计算分
* 所有内容的数据将以活动截止后三日（UTC+8）的最终数据为准，进行统一统计
