# ✍️ TermMax Mindshare 专属创作者激励计划

为了进一步推动更多用户参与 TermMax Mindshare Campaign，带来更多真实讨论并提升社区活跃度，我们特别推出专属创作者激励计划，面向愿意贡献高价值内容的优质创作者。加入计划后，您的内容将同时计入官方 Mindshare Leaderboard 与本计划独立榜单，享受双重激励，进一步放大曝光与奖励回馈。

**注意事项：**

1. 本激励计划排行榜与 TermMax 官方 Mindshare Leaderboard 为独立榜单。官方榜单面向所有用户，属于持续活动；而本计划为专属创作者的限时活动，仅面向符合条件的创作者。
2. 只有报名成功且在活动期内完成最低参与要求的创作者才能进入该榜单评选范围；未达成最低要求者将不具备任何领奖资格，包括保底奖励。
3. 在正式加入本激励计划前，请仔细阅读以下事项。若您符合参与条件，[欢迎报名](https://forms.gle/7fZCBQ7nDxW2Crfu7)。报名后并不代表您已正式加入本计划。若报名成功，官方将在报名截止后三日内联系您。

### 一、报名时间

自公告发布起至 12 月 4 日 23:59 UTC。

### 二、参与资格

#### 1. 报名条件：

* X 粉丝 ≥ 1,500
* 过去 30 天内至少有一篇推文浏览量 ≥ 5,000

#### 2. 内容要求：

成功报名加入本计划的创作者，需要满足以下最低要求才能进入排行榜排名，否则排名无效。

* **与官方互动：**&#x5728;活动期间，参与计划的创作者<mark style="color:orange;">至少需与项目官方推特互动三次</mark>（包括评论、转发、引用推文等形式，不限具体方式），以协助放大关键信息。官方可能会指定需要互动的推文。
* **内容数量：**&#x6D3B;动期间，参与计划的创作者<mark style="color:orange;">至少需发布三条内容</mark>。
* **内容方向：**&#x5185;容形式不限（长推、图文、短视频均可），长度随意。内容需要覆盖以下要点：

> → 提到 TermMax Mindshare Campaign（嘴撸）和 MP (Mindshare Points)\
> → 结合项目介绍，如项目亮点、Alpha Market 玩法、如何参与空投、官方动态等\
> → 需要 @TermMaxFi

* **内容质量：**&#x5185;容须体现明显投入，杜绝抄袭、水贴或低质量内容，否则排名无效。

### 三、激励结构

<mark style="color:orange;">**我们提供多重激励机制**</mark><mark style="color:orange;">：</mark>除了官方 Mindshare Leaderboard 自带的积分奖励，本计划独立榜单还提供基础保底奖励以及额外进阶奖励，确保您的付出得到充分回报。

所有奖励将在该计划结束后 **10 个工作日内**，根据确认后的最终排名完成结算发放。

#### 1. 基础奖励（保底）

所有符合上述最低参与资格要求的创作者，将获得 <mark style="color:orange;">100 USDT</mark> 作为保底奖励。

#### 2. 核心进阶激励

进入该计划榜单<mark style="color:orange;">前 10 名</mark>的创作者将获得进阶奖励。

| **排名**   | **奖励**                                                                |
| -------- | --------------------------------------------------------------------- |
| 第 1 名    | 500 USDT                                                              |
| 第 2 名    | 350 USDT                                                              |
| 第 3 名    | 250 USDT                                                              |
| 第 4-10 名 | 根据最终排名依次获得一次性 Mindshare Points（MP），奖励范围从 3,000 MP 至 500 MP，排名越靠前奖励越高。 |

### 四、排名与评分机制

我们将通过加权公式对内容进行评估，以尽量确保评分的公平性。

#### **1. 数据收集与统计范围**

由于不同创作者在活动期间发布内容的时间不一致，所有帖子的浏览量和互动量均以发布后的 72 小时内数据为准。数据由系统通过 API 自动抓取。

#### **2. 评分说明**

为尽可能确保排名公平与公正，具体加权公式不对外公开。官方将通过自动化评估机制进行初步排名，并结合人工审核结果进行最终评定。
